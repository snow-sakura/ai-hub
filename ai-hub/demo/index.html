1核心工作流

一条需求从输入到入库，AI 自动完成「分析 → 编写 → 评审 → 修订」四步闭环，人工只需最后确认采用。

📄 需求输入→🔍 需求分析→✍️ 用例编写→⭐ AI 评审→♻️ 用例修订→📥 采用入库
⚡ 单任务流式生成SSE 实时推送每一步思考与 token 流，任务中断重启后自动回收恢复。

2模型分级与序列调度（v1.4 核心）

同一份长需求按 Markdown 标题（# / ##）自动拆分为子任务序列：免费模型 → 串行（并发 1）保护配额；付费模型 → 并行（≤3 槽位）提升吞吐。

🆓 免费 · 串行ollama / 标注免费模型，严格逐个执行，失败即暂停可重跑。
💎 付费 · 并行Semaphore 并发槽位（默认 3），泳道可视化，单任务失败不影响其它槽位。

3定时任务 · 真实执行

cron 到点后自动创建真实生成任务（exec_ref 可跳转），日志记录真实耗时与结果。
