帮我写一个Vue3的防抖函数
▶ 🧠 已深度思考(用时3秒)
用户需要一个Vue3的debounce函数。考虑到Vue3的composition API，应该使用ref来存储定时器，同时考虑组件卸载时清除定时器。可以使用lodash-es的debounce或者自己实现。

当然，以下是 Vue3 组合式 API 的防抖函数实现：

import { ref, onUnmounted } from 'vue'

export function useDebounce(fn, delay = 300) {
  const timer = ref(null)

  const debouncedFn = (...args) => {
    if (timer.value) clearTimeout(timer.value)
    timer.value = setTimeout(() => {
      fn(...args)
      timer.value = null
    }, delay)
  }

  onUnmounted(() => {
    if (timer.value) clearTimeout(timer.value)
  })

  return debouncedFn
}

使用方法：

  • 在 setup 中调用 useDebounce(searchFn, 500)
  • 返回的函数可直接绑定到 input 事件
  • 组件卸载时自动清理定时器

用户希望加上TS类型标注。需要为函数参数和返回值添加类型，同时保留原有的功能。

以下是 TypeScript 版本：

import { ref, onUnmounted } from 'vue'

type AnyFunction = (...args: any[]) => any

export function useDebounce<T extends AnyFunction>(
  fn: T,
  delay: number = 300
): (...args: Parameters<T>) => void {
  const timer = ref<ReturnType<typeof setTimeout> | null>(null)

  const debouncedFn = (...args: Parameters<T>) => {
    if (timer.value) clearTimeout(timer.value)
    timer.value = setTimeout(() => {
      fn(...args)
      timer.value = null
    }, delay)
  }

  onUnmounted(() => {
    if (timer.value) clearTimeout(timer.value)
  })

  return debouncedFn
}
